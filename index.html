PERIODIC DISPLAY

Replicate

1 × 1 × 1 · Original cell

Total copies along each periodic cell vector, including the original. A value of 1 keeps that direction unchanged. Triclinic cells follow their tilted vectors. Analysis uses the original atoms; only rendering is repeated.

TRAJECTORY MOTION

Displacement

Not calculated

Current position minus reference position, matched by atom ID. Components and magnitude become atom properties for Color by and Vector arrows. Turn off minimum image for continuous unwrapped motion beyond half a periodic cell.

Open this tool to start calculating. Cancel clears its results and stops frame updates.

STRUCTURE STATISTICS

Coordination distribution

Radial distribution g(r)

Not calculated

Normalized g(r) requires a fully periodic three-dimensional cell. Element filters calculate partial pair distributions. Statistics use the original structure before display replication.

Choose a distance range and calculate the pair distribution.

CRYSTAL STRUCTURE

Common neighbor analysis

Not calculated

Adaptive CNA chooses a local cutoff for each atom. Identifies FCC, HCP, BCC and icosahedral environments; other environments are marked Other.

Calculate to color by crystal structure. The legend checkboxes control visibility.

DEFECT ANALYSIS

Central symmetry

Not calculated

Auto identifies local FCC, HCP and BCC environments, including mixed structures.

AtomEye normalized central symmetry: Auto uses 12 neighbors for FCC/HCP and 8 for BCC. Ideal HCP has a finite value because it is not centrosymmetric. Dimensionless; differs from conventional CSP in Å².

Runs on the complete structure, including hidden atoms.

TEMPLATE MATCHING

Polyhedral template matching

Not calculated

Matches local polyhedra to crystal templates. Fits above the RMSD threshold are Other; 0 disables this threshold. Diamond and graphene templates use additional neighbor shells.

Results include structure type, RMSD and nearest-neighbor distance.

ATOMIC ELASTIC STRAIN

Ideal lattice reference

Not calculated

Element presets give editable reference lattice constants in Å. For alloys or other temperatures, supply the stress-free values appropriate to your system.

PTM correspondence gives Green–Lagrange elastic strain relative to the reference crystal, including absolute lattice expansion. Tensor components use local crystal axes.

Unknown numeric atom types need an element or explicit lattice parameters. This is not displacement strain between trajectory frames.

TRAJECTORY DEFORMATION

Reference frame strain

Not calculated

Fit the current neighbor vectors to a selected reference frame using stable atom IDs. Green–Lagrange strain uses Cartesian axes; insufficient or unmatched neighborhoods receive NaN.

Open a trajectory and choose a reference frame.

LOCAL GEOMETRY

Local shear

Not calculated

AtomEye-style shear measures the shape of each local neighbor environment in this frame. It does not require a reference frame or a matched crystal template.

Calculate a local geometric shear indicator.
