## 临时显示与正式结果的边界

外观快照不写入目标 `frame.properties`。状态提示清楚标记借用外观的来源帧；数据相关旧图例控件在等待期间暂停编辑，着色量切换和相机操作仍可用。没有可靠原子对应时保留完整旧场景，不能按行号假定两个 CFG 的原子对应。

统计、全局属性、原子详情、表达式和后续计算读取真实目标帧。Surface 使用独立的正式可见性 getter：即使显示仍借用旧 mask，表面输入也只来自当前帧真实过滤；依赖未就绪则继续等待。统计导出同时拒绝显式标为 preview 的图例或属性。

截图/电影先等待当前分析与请求的坐标准备；正式外观仍不可用时返回错误，不能默默导出旧帧颜色。普通浏览和快速播放允许临时显示，科学结果没有因此放宽。

## 预热与资源管理

- 保留结构/分析 Worker、CPU 模块、DXA 内核和 GPU device/pipeline 预热。预测任务只在资源空闲后开始，前台工作优先，取消预测不重建这些资源。
- 场景切换复用两组缓冲及原有着色器，不再复制第三份完整场景。源关闭、取消、源替换及 context 丢失会清理保留状态和绘制等待者。
- 当前显示帧是 CPU 字节预算的唯一超额例外：若一帧本身超过预算，仍允许打开，但不能因此无限保留相邻帧。GPU、预测、DXA 和外观另有各自预算。
- 复杂 DXA/网格不在空闲预测器里额外启动整条昂贵流水线；采用有限结果缓存、请求合并和完整场景提交。预计算不会为了“看起来快”抢占当前请求或扫描全部轨迹。

## 验证

最终全仓 **2,532 项测试通过**，零失败、跳过或取消，覆盖精确解析、CPU/GPU、原生 DXA、过滤依赖、配置、缓存、导出和渲染。

生产 Chromium 回归检查了下列实际行为：

- ID 重排后颜色及隐藏分类稳定；新 ID 使用默认外观；目标帧尚无科学属性时，旧值仍仅存在于显示层。
- 按住鼠标跨越 CNA 完成继续旋转；无关固定邻居 CSP 完成时，CNA 颜色新增上传为 0。
- 完整旧场景的像素保持、等待时相机移动、取消恢复、过期 token、完整提交及 context 恢复。
- Complete 实际绘制最终帧后才前进；扣住 CNA 650 ms 后不再额外等待完整一秒；无关 CSP 不阻挡前进。
- 20 FPS Preview 取消过期导航；配置恢复帧率/模式但不会自动开始播放。
- 已有 image flags 的 CFG 在 CNA 尚未完成时就显示正确 x=12 Å，无历史推断请求；默认 File 与独立 inference 开关回归保留。
- PNG 等待正式结果；固定色标跨帧稳定；失败后保留着色意图；已缓存完整帧回访不重复计算。
- 普通及隔离部署、390 px 手机布局；FPS 输入宽 57 px，时间轴高 136 px，各控件及坐标轴保持分离。
- 独立真实 CPU/WebGPU 预测验证：四阶段链均复用，前台新增计算为 0，科学属性未提前发布，预热 Worker/device 保持。

原始随机切帧与 CNA 尾延迟有回退，不能删除这些样本或断言它们都是噪声。随后追加的 8 次阶段诊断使用相同 850×778 canvas、50k 原子和相机：输入至 `setFrame` 中位数 4.90→4.80 ms，上传提交 0.50→0.45 ms，render CPU 均约 0.30 ms，每次均 1 次绘制；主要等待在上传后至 RAF（722.85→743.35 ms），CPU profile 大部分为 idle。这定位了本次软件渲染环境中的主要等待位置，没有证明实体 GPU 的尾延迟或所有场景均提速。

缓存和预览以额外内存换取连续显示。CNA 阶段结束时浏览器 `usedJSHeapSize` 快照为 22.02→47.56 MiB；这不是强制 GC 后的保留量或峰值。原始堆和 backing storage 数值全部保留，新增缓存均有预算，不能据此声称内存更少。首次失败的测量尝试只有 instrumentation 启用错误、没有生成数据集；正式对照使用相同修正脚本，未混入失败试验。

## 实际限制

原生 Blob 读取、单次大数组分配、GPU 驱动提交，以及已进入不可中断的串行 Wasm 调用，无法靠 JavaScript 事件循环在中途暂停。普通未隔离部署中取消这种已运行的 Wasm，仍需安全终止 Worker；阶段 ACK 和导航合并减少触发，隔离部署可使用共享取消标志。不能为了保留预热而让过期任务继续占用前台或提前归还 CPU 许可。

第一次显式启用缺失 image flags 的历史推断，仍需要读取必要历史。昂贵分析超过帧间隔时，Complete 会如实降速；Preview 可以跳过中间目标。软件 GPU 的浏览器检查证明行为与生命周期，不能用来宣称实体 GPU 帧率。
