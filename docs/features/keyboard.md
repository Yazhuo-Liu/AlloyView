# Keyboard shortcuts

Open the **?** button beside the viewport download controls, or press **?**, to
show all commands. Each command has a label, a group, one or more keys and an
availability check. Shortcuts do not run while an input, select, editable text
area or modal dialog has focus. Ctrl, Command and Alt combinations remain browser
or operating-system shortcuts. Escape keeps its existing panel behavior.

## Camera step gearbox

Press **0–9** with the structure loaded to choose a camera step size. Gear 5 is
the initial value; each gear doubles the previous gear. The multiplier is
`2^(gear − 5)`: gear 0 gives 1/32×, gear 5 gives 1× and gear 9 gives 16×. A brief
viewport indicator reports the selected gear without blocking interaction.

At gear 5, orbit and roll steps are 5°, pans move by 2% of the model radius in
the camera's screen plane, and zoom changes the distance or parallel field width
by an exponential factor `exp(±0.05)`. Rolling releases **Keep Z pointing upward**
and updates the same camera values as the Adjust view panel. Movement keys can
be held to repeat. Camera presets, reset, theme, downloads, frame steps and
play/pause act once per press.

| Default key | Action |
| --- | --- |
| Arrow Left / Right / Up / Down | Orbit camera |
| Shift + Arrow Left / Right / Up / Down | Pan in the screen plane |
| Q / E | Roll left / right |
| + or = / − or _ | Zoom in / out |
| R | Reset camera |
| F / B | Front / back parallel view |
| L / Shift + L | Left / right parallel view |
| T / Shift + T | Top / bottom parallel view |
| [ / ] | Previous / next frame |
| { / } | First / last frame |
| Space | Play / pause trajectory |
| , / . | Move selected slice back / forward by its own step |
| Shift + F | Flip the selected slice's retained side |
| P | Download PNG with the current image settings |
| D | Switch light / dark theme |
| ? | Open the shortcuts dialog |

Slice steps use the plane's own step in Å and are independent of the camera
gear. A selected plane can be moved after switching to another tool; flip is
unavailable for slabs. Frame commands use the existing trajectory controls,
including the first/last boundary checks and incremental indexing.

## Change shortcuts

Select **Change** next to a command and press the desired key. Printable symbols
use the character generated by your keyboard layout rather than a US physical
key position. Letters are case-insensitive unless Shift is held. A command's
replacement uses a single key, optionally with Shift. Digits 0–9, Escape, Tab,
Enter and Ctrl/Command/Alt combinations are reserved.

If another command already uses the key, the dialog reports the conflict and
keeps the existing assignments. Press another key or Escape to cancel capture.
**Reset defaults** restores every initial binding and gear 5. Bindings and the
gear are stored in versioned localStorage and survive reload; disabled browser
storage still allows changes for the current session. Malformed or conflicting
saved settings fall back to the defaults.

The native modal dialog confines Tab focus, supports Escape and restores focus
to the opener. It follows the theme and adapts to narrow screens. The dialog and
gear indicator are HTML overlays and do not appear in exported images.

Implementation: `src/keyboard-commands.js`, `src/keyboard-controls.js`.
