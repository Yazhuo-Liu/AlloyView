# DXA 全局算法改造计划

设计日期：2026-10-21。代码基线：`d1bfe2f4f810c4c204bc0ddad417332fafbd7368`，已核对与远端 `main` 一致。

本文是下一轮设计与验收计划。已有实现及实测结果见 [K4 报告](PERFORMANCE_DXA_K4.md)。所有新增收益目标均为候选的准入标准，不是已实现的性能承诺。

实施进度（2026-10-21）：P0／P1 的诊断、基准和验证基础已落实，具体实现、
严格比较状态及覆盖限制见 [P0／P1 报告](DXA_P0_P1.md)。以下保留原阶段划分，
P2 之后的算法候选及 R1／R2 研究仍未采用。

## 1. 目标与优先级

首要目标是减少用户从点击分析到结果可用的等待，同时保留 Worker、Wasm、GPU 预热、共享 CPU 配额、线程池和安全的内存复用。优先改进当前 CPU/Wasm 全局算法；GPU 重写及全新周期几何内核作为独立研究方向。

推荐主线为：**细分诊断和正确性基线 → 单线程 Geogram 内部热点 → 真正的 PDEL 扩展性 → 追踪及有序拓扑构建 → 生产集成**。周期点集压缩、原生周期 Delaunay、跨帧增量拓扑并行研究，达到独立验收条件后再进入生产路线。

最终采用的连续边布局、追踪工作区和连续 ghost 面查找保留。此前实测无收益的面载荷批处理及 frontier-pruning 不作为默认待实施项；只有新诊断指出不同瓶颈时才重新评估。

## 2. 当前证据与收益边界

下表来自 K4 最终生产产物的普通内核单线程记录，单位为 ms。它们用于定位方向，不能替代下一轮的新基线。

| 样本 | 原子数 | 完整原生提取 | Delaunay | Delaunay 占比 | 接口网格阶段 | 追踪阶段 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| HEA | 28,800 | 616.86 | 231.75 | 37.6% | 106.02 | 53.41 |
| Fe | 60,229 | 1643.38 | 699.44 | 42.6% | 331.25 | 0.12 |
| NiGB，沿 Z 复制两次 | 259,808 | 11682.68 | 5380.34 | 46.1% | 2462.85 | 789.83 |

接口网格阶段包含分类和构造；追踪阶段也包含实际 junction 合并，不能把它们视为单一算法耗时。阶段中位数与总中位数的比值只是近似占比。即使 Delaunay 单独快两倍，其余部分不变时，完整提取也只约快 1.23／1.27／1.30 倍。这是 Amdahl 估算，不是预测结果。

已有四线程 K4 对照固定 Delaunay 为单线程，只从下游启用四线程，不能据此推断 PDEL 四线程速度。历史文档中的 2.1 倍扩展性及约 400 ms 串行下限来自旧版本，也不能直接作为本轮指标。

独立诊断显示：HEA／Fe／NiGB 的输入与周期点准备约为 1.05／7.41／42.24 ms，Geogram `set_vertices` 则约为 228.68／677.89／5227.67 ms。这些是诊断样本，不是正式性能对照，但足以说明仅并行化外层坐标循环的收益空间有限。

NiGB 的 259,808 个原子扩展为 857,324 个几何点，生成约 516 万个四面体，其中约 156 万个为本地四面体。周期扩展是重要的潜在空间，但减少图像必须有周期完备性证明。

原始记录：[单线程](https://github.com/Yazhuo-Liu/AlloyView/blob/main/docs/benchmarks/dxa-k4-adopted-one-thread.json)、[固定拓扑四线程及诊断](https://github.com/Yazhuo-Liu/AlloyView/blob/main/docs/benchmarks/dxa-k4-adopted-four-thread.json)。

## 3. 必须维持的契约

1. 保留全局周期连接、倾斜晶胞、混合 PBC、薄晶胞的多层图像，以及完整邻居和搜索参数含义。不能按空间任意切块后直接拼接位错网络。
2. 兼容路线保留输入／周期图像顺序、扰动序列、随机种子、精确几何谓词、首次边方向、邻接遍历及提交顺序。不能通过放宽容差、减少搜索深度或跳过空结果样本获得速度。
3. 算法输出包括所有原子标签、晶体与变换、Burgers 向量、完整曲线、周期绕行、junction 图、缺陷网格和 Surface 网格。仅比较线条数量或总长度不足以验收。
4. 预热继续开启，并沿用共享 CPU 预算。独立 Worker 模式继续以一个全局几何内核协调；增加私有 Worker 不等于可以无代价共享可变四面体图。
5. 取消、分配失败和线程启动失败必须在拓扑一致的安全点退出。正常安全点取消后复用已预热内核；非共享模式确需终止 Worker 时，沿用现有重建恢复机制。异常时可以丢弃本次原生会话，但不能发布半成品。
6. 每个新增缓存均定义所有者、寿命、容量上限及失效条件；帧、坐标修订、晶胞、PBC、选择、晶格参数及搜索参数变化不能命中旧科学状态。
7. DXA 与 Surface 共用几何代码；所有几何改动都验收两条路径，包括 `coverDomainWithFiniteTets` 的辅助角点和无限单元语义。

## 4. 正确性分层

**兼容改进路线。** 数据布局、工作区复用、有序压缩及保持算法顺序的实现改进，要求固定输入和固定单线程几何下完整科学输出与网格字节一致；已有冻结哈希继续有效。

**真实并行路线。** 当前 PDEL 插入调度就可能产生不同的合法核心折线，因此不能强行把 BDEL 的字节哈希当成所有线程数的唯一判据。先固定“同后端、同线程数”的旧版输出分布和已知非确定性，再检查几何合法性、晶体学、完整网络连接及周期拓扑。允许的差异必须逐例解释，容差来自已有扰动量或数学误差界；不能为通过测试而扩大容差。

**新算法研究路线。** 改变插点顺序、周期表示或跨帧拓扑时，同时保留严格参考实现、几何不变量和外部参考。规范化只能消除编号、方向或周期表示等可证明的表达差异，不能隐藏线段丢失、junction 改接或晶体变换差异。未证明等价的候选保持实验状态。

### P0：先拆开真正的热点

在现有可选 `onDxaProfile` 上扩展诊断，记录：

- Geogram：BRIO 随机化、Hilbert 排序、初始四面体、点定位、冲突区域发现、删除／新建单元、末尾压缩与重编号。
- PDEL：各线程插点数量、定位失败、回滚／重试、等待时间、四面体池高水位、耗尽次数及串行补插尾部比例。
- 数值路径：谓词快速过滤与精确回退的计数。使用专门诊断构建或线程局部累计，避免在正式计时中给每次谓词增加时钟或共享原子操作。
- 追踪：按回路深度分别记录主搜索、回路扩展、实际 `joinSegments`、secondary segment 创建和清理；统计搜索工作量、组件分布及成功／失败原因。
- 网格与晶体图：区分分类、alpha 测试、面提交、半边连接、cluster 遍历和 transition 搜索。

特别修正计时说明：`wasm/dxa.cpp` 的 “Connect dislocation junctions” 调用的是 `finishDislocationSegments()`；实际 `joinSegments()` 在 `traceDislocationSegments()` 内。当前该外层阶段很短不能证明 junction 合并很便宜。

现有 profile 只挂在主线程的 `thread_local` 上，不能直接用它收集 PDEL 子线程数据。新增线程计数使用私有结构，在 join 后汇总；容量及溢出标记也必须纳入诊断接口验证。

交付：分阶段 CPU 时间、工作量、命名结构容量和可取消点分布。关闭诊断时结果和算法路径不变；诊断时间不作为正式加速证据。

### P1：建立可用于算法变化的基线

保留现有固定拓扑基准，新增独立的真正全流程 BDEL／PDEL 对照模式，分别比较旧版与候选产物。记录后端、线程数、构建工具、参数和 JS／Wasm 哈希，避免混淆下游并行和几何并行。

样本至少包含：三组真实结构；BCC 环、FCC screw、partial／stacking fault／twins、HCP 与 diamond；junction 密集网络；NiGB 等最终为空但搜索量大的输入；正交／倾斜／混合 PBC；薄晶胞、真空层、周期角点、几乎共面／共球点；重复坐标和其他已有输入拒绝条件；Surface 辅助角点；短轨迹中的平移、边界穿越、微小形变、晶胞改变和拓扑事件。

构造 junction 密集样本时先确认其物理意义与参考结果，不能只用任意扰动的合成结构替代真实位错结点。

扩展外部 oracle 为完整网络和网格数据。现有研究脚本的结构直方图和少量线段摘要不够；固定参考程序版本和全部参数，不把不同版本差异直接判为本项目错误。

交付：完整比较器、固定种子几何压力样本、变换性质检查，以及同线程重复运行的差异记录。输入重排等可能改变已有扰动绑定的变换不能误设为字节一致；这类检查使用经过说明的物理不变量。

### P2：保序优化单线程 Geogram

先根据 P0 选择一个热点，而不是同时重写所有数据结构：

1. 若分配／增长显著：复用定位、冲突区、排序和压缩的临时空间；分离容量与有效长度，清理完整会话状态，限定保留预算。Geogram 已有数组与空闲链表，应针对实际反复分配位置改进。
2. 若排序显著：优化现有 BRIO／Hilbert 的临时数组和调度，验证输出排列完全一致。当前已启用空间排序，不能再次把“加入 Hilbert 排序”列为新增收益。
3. 若压缩／重编号显著：研究稳定计数、前缀和、分段写入；保留旧的 cell 顺序，完整更新邻接、无限单元和映射，避免第二份全尺寸拓扑长期并存。
4. 若点定位／冲突遍历显著：改善访问局部性和只读重复计算，在旧顺序内复用定位提示。改变插点顺序、定位规则或精确谓词执行语义的候选转入研究路线。
5. 输入预分配、周期点准备和本地编号只做有证据的低成本改进；目前不把它们作为主要加速来源。

每项独立构建、验证和测量；不把多个未验证修改捆绑成一个新内核。

具体内存候选包括 PDEL 大数组的重复初始化，但只有逐路径证明空闲槽 sentinel 无读前依赖、每个发布单元的全部字段已写入后，才能消除初始化。现有四面体压缩依赖原地递增扫描及 `old2new[t] <= t`，不能直接并行化该循环。优先研究映射建立后相互独立的邻接重写；稳定并行压缩需先解决读写覆盖和双缓冲峰值。

### P3：提高真正 PDEL 的扩展性

现有 PDEL 已并行插点，并具有串行起步、各线程四面体池、失败回滚和池耗尽后的串行插入尾部。优化按诊断结果选择：

- **池耗尽或尾部显著：** 在总预算内调整各线程容量和增长策略，减少本可避免的串行尾部。保留可证明的所有权与屏障规则，测试所有线程同时耗尽、取消与创建线程失败；工作线程仍持有裸指针时不能扩容底层数组。
- **线程失衡显著：** 研究分区粒度、各轮工作量和安全阶段边界上的重分配。不能直接在互相依赖的插入 Worker 外再套任意 work-stealing 调度。
- **冲突／回滚显著：** 研究降低相邻插入区域冲突的分区或批次；保持稳健谓词和完整冲突腔。此类变化可能改变合法三角剖分，按研究路线验收。
- **小输入调度成本显著：** 校准串行／并行切换阈值和阶段线程数，始终服从共享预算，复用已建好的线程池；按实际点／单元工作量评估，不能只依赖原子数。

交付：1／2／4 核的真实扩展性、峰值与尾部分析；8／16 核需在有对应实际 CPU 配额的环境补测。记录资源不足的回退原因。固定 4 核容器中的 16 线程不能作为 16 核性能证据。

### P4：接口网格与非隔离路径

现有连续边／ghost 面查找、并行边界掩码和 wrapped-vector 预处理继续使用。先区分分类与提交耗时：

- 分类热点：减少重复读取和临时对象，核对向量／变换复用；必须同时检查数值退化和同一边跨晶体转换的行为。
- 提交热点：预估容量、改进半边连接查找或使用保持原顺序的分段扫描；保留原始顶点／面编号、错误触发顺序和共享 Surface 语义。
- 非隔离主机：重新测量快照打包、私有 Worker 分发和分类总和；仅在总成本有收益时使用卸载。任何自适应选择都保留全局内核和 Worker 预热，并检查共享 CPU 预算下的竞争。

较大的表示层候选是消除 `InterfaceMesh` 同时持有整数 Surface 拓扑和内部指针拓扑造成的重复存储，研究共用紧凑索引。应替换已有表示，而不是长期再附加一份完整邻接表；须检查追踪可变状态与通用 Surface 生命周期的分离。

此前面载荷批处理在密集样本上使网格阶段变慢约 10%，且多用约 1.1 MB。没有新的成本证据时不重启同一方案。

### P5：追踪、junction 与晶体图

先评估两个更容易独立交付的映射候选：

- `ElasticMapping` 当前每批并行映射重新建立各线程的 `CrystalPathFinder` context。统计多批次下 atom-count visited bitset 和节点页的创建／清零成本，再尝试一次映射阶段内跨批复用有界 context；它不是当前每条边都重新创建 finder。保留原序提交、遇到未知 transition 后的串行重算，以及取消／异常后 touched 状态的完整清理。
- 对已经存在的直接 cluster transition 研究受限查找加速，保留第一次匹配语义和 generation 失效。不能预先并行计算所有 transition：当前路径搜索会按遍历顺序选择并缓存同距离路径，提前填缓存可能改变结果。小图应直接沿用原查找。

第一层沿用原始搜索顺序：根据 P0 减少重复转换／邻接读取、复用有限只读计算，明确 visited、回路交点、前驱和 transition 缓存的更新边界。现有 1 MiB 追踪页保留策略继续使用；默认真实样本本来就没有减少页分配次数，不能再以减少 malloc 作为未经证明的主要收益。

第二层研究只读准备与串行提交：候选搜索只读取不可变数据，写操作列入明确的提交清单；先验证缓存失效和内存成本，再考虑并发。按深度统计失败搜索是否有重复工作；任何剪枝都需要证明不会漏掉合法 Burgers 回路。

完整 Burgers 搜索实际依赖可变的 edge／face circuit 标记。若把完整搜索提前到提交之前，必须记录并校验相关状态版本或读集；前一个回路的提交可能改变后续可走路径、首次发现和交点，失效候选必须按原序重新搜索。无法低成本证明候选仍有效时，只并行不可变数据准备，搜索本身保持串行。

第三层才评估组件并行：图连通性必须包含周期对应、回路能访问的边界、junction 可能连接的面以及晶体 transition 依赖。单纯“空间上分开”或“网格上暂时不同组件”不足以证明独立。只并行被证明互不影响的组件，使用组件私有状态；无法证明时保留全局串行搜索。即使组件独立，按最小种子编号拼接也不足以维持原输出：还需重放每个深度的 extend→seed→join 事件、动态 dangling node 和 segment 创建／删除的原顺序。先统计按实际搜索工作量加权的最大组件占比；若单一组件占绝大部分，优先放弃复杂的组件调度。

junction 合并单独看真实计时和样本，先研究将反复 `find + vector.erase` 改为安全点的稳定压缩，以及长曲线 deque 的重复拼接成本。必须审计所有中间观察点，保留幸存 segment 顺序、ring 顺序、周期 shift 和中心累加顺序，再考虑候选生成并行。cluster 阶段也先量化，保留首次发现和变换选择语义；不采用改变晶体编号或变换路径的普通并行 union-find 替换。现有 supercluster 已有相应并查结构。

### R1：周期点集与原生周期 Delaunay

这是潜在收益大、正确性风险也最大的方向，分两个实验：

1. **证明充分的图像集合：** 根据真实欧氏几何和 ghost-layer 定义建立保守充分条件，移除被证明不可能影响所需局部四面体的图像；先在小结构与现有完整扩展逐单元对照。只有经验性邻近规则时，候选不能进入生产。
2. **周期原生表示：** 顶点使用原子 ID 加整数图像偏移，设计周期邻接、局部单元归属、稳健谓词和输出展开。独立处理倾斜、混合 PBC、多层图像及 Surface 的有限覆盖辅助点。

捆绑 Geogram 的 `PDEL` 是 `ParallelDelaunay3d`，不是 `PeriodicDelaunay3d`。后者以单一周期长度和立方域图像逻辑工作，不能直接替换一般晶胞。把倾斜晶胞仿射映射到单位立方体会改变欧氏 Delaunay 度量，除非同时严谨处理该度量。

交付：周期完备性论证、逐单元对照器、内存模型和失败后重建的参考路径。保持原完整扩展实现作为可靠回退；仅在受验证的适用域启用实验候选，不把其他晶胞静默按立方域处理。

### R2：轨迹的跨帧复用

先区分三种不同强度：

- 只复用数组容量和线程池：不复用科学状态，属于 P2 的低风险范围。
- 复用 BRIO／Hilbert 排列或定位提示：坐标仍全部更新；先评估完整重建的性能和输出变化，不能假设排序缓存一定更快。
- 增量维护四面体：需要检测移动后的所有相关定位／in-sphere 条件、拓扑翻转、PBC 图像变化和 ghost-layer 变化；维护撤销／重建边界。位移很小不代表 Delaunay 拓扑不变。

配置、原子集合／顺序／ID、选择、晶胞、PBC、扰动尺度和 ghost-layer 范围变化时必须失效；跨帧选择与帧跳转不能读到半更新图。小步轨迹、突然大位移、晶胞形变与位错反应分别测试，包含完整重建后的科学比较。即使复用了合法几何拓扑，结构分类、弹性映射和位错网络仍按新帧更新。

交付：单帧路径与轨迹路径各自的端到端收益，以及缓存驻留预算。不能以加速重复同一帧的缓存命中来代表新帧分析速度。

### P6：集成与发布

每个候选单独提交，重建普通和线程版 Wasm，更新 vendored 修改说明与校验清单。保留相关原始结果及被拒绝候选的原因，后续阶段以最后已采用版本为基线。

验证普通托管和跨源隔离托管，覆盖 DXA、Surface、真实预热、池增长、共享配额竞争、取消、启动失败和内存不足恢复。测试选择新帧／新源时的旧任务失效，不让迟到结果覆盖当前数据。

将阶段结果写回 K4 报告与 TODO，区分“实现并采用”“测量后拒绝”“研究未完成”。

## 6. 统一验收标准

| 维度 | 验收要求 |
| --- | --- |
| 科学正确性 | 兼容路线完整字节／哈希一致；真实并行和研究路线满足预先定义的完整网络、晶体学、周期与几何不变量，所有差异可解释 |
| 数值几何 | 单元约定方向一致与邻接互反、局部／ghost 归属、无非法重复／遗漏、适用输入上的空球条件；按实际扰动坐标和退化规则验证，保留原有错误语义 |
| 性能协议 | 旧／新版本交替运行；诊断关闭；分别记录用户等待、原生计算与阶段时间；正式计时不与构建或其他基准抢 CPU |
| 样本数量 | 候选筛选每组至少 3 次，采用前主要样本至少 7 次，并在独立批次复核；昂贵大样本记录实际次数及不确定性 |
| 采用门槛 | 优先要求目标实际场景端到端中位数改善至少 5%，且超过波动；其他代表场景超过 5% 的可重复退化视为阻断，需收窄适用域或撤回。显著内存／取消收益可单独立项，明确性能代价 |
| 内存 | 区分结构有效字节、容量、高水位、Wasm 堆与进程 RSS；不得超过现有任务预算，不得随帧数无界增长。与速度交换的额外容量必须量化并证明准入安全 |
| 冷／热体验 | 分别测试刚打开应用、文件就绪后第一次分析和后续帧；不关闭正常预热以制造速度对照，也不增加无收益的后台完整提取 |
| 恢复能力 | 覆盖排序、插点、压缩、追踪、合并、输出等安全点的取消；恢复计算结果正确，已预热资源可复用；无死锁、泄漏或重复回退循环 |
| 平台范围 | 1／2／4 核先完成真实配额测试，8／16 核独立补齐；Node 与真实浏览器均验证，物理 GPU 性能不由软件渲染测试替代 |

5% 是建议的工程准入门槛，不是统计显著性保证。若样本波动接近或超过收益，增加独立批次或拒绝候选；不能挑选更好的一次测量覆盖全部记录。

## 7. 第一轮可执行清单与阶段出口

1. **提交 A：诊断。** 拆开 Geogram 与真实 junction 计时，加入线程工作量和内存计数；科学输出保持不变。
2. **提交 B：基准与比较器。** 同时保留固定拓扑和真正 PDEL 协议，补齐 junction、退化周期和 Surface 样本。
3. **决策点一。** 根据排序、插入、冲突、压缩和尾部占比，只选一个主要热点进入实现；输出可追溯的选择理由。
4. **提交 C：保序热点改进。** P2 中最有证据的一项，分别在单线程与线程内核测量。
5. **提交 D：PDEL 优化。** 由真实诊断决定是池容量、负载还是冲突；同输入和同线程数对照。
6. **提交 E：次级瓶颈。** 选择 P4 或 P5；允许分别提交，避免同时改变几何和搜索导致差异难以定位。
7. **决策点二。** 评估 R1／R2 是否值得投入；没有周期完备性或增量正确性论证时，保留为研究结果。
8. **每个提交采用前完成 P6。** 更新产物、报告、原始测量与剩余待办，避免等待整个研究路线结束才交付已验证收益。

近期优先交付 A、B，再实施由数据选出的 C、D。完整计划不以“所有阶段都并行”为完成标准，而以准确、可恢复且可测量的用户等待改善为准。
